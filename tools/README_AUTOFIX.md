# Auto-fix cycle

## Required environment variables
- ADMIN_URL
- ADMIN_EMAIL
- ADMIN_PASS
- DELETE_TARGET_EMAIL
- OPENAI_API_KEY
- MAX_ITERS (optional, default 5)
- SLEEP_SECONDS (optional, default 120)
- OPENAI_MODEL (optional)

## Run
Double-click:
tools\run_cycle.cmd

## Reports and logs
- tools\test_report.json
- tools\test_artifacts\
- tools\autofix.log
